Each region has a display name (e.g. Buffalo), a short name used by MeshCore (e.g. buf), and a level for its depth (lower = broader, e.g. country 1 → state 2 → city 3). Pick a region in the list, then use the map tools to outline where it applies — every region needs an area (the root region at the top of the list is the one that applies everywhere).

Draw with the tools at the top-left of the map. New shapes fill the selected region; drawing again adds a new region.
