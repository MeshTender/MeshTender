Keeping its settings

Before installing, you'll be asked whether to erase the device. If it already runs MeshCore, leave that unchecked: it keeps its public key, name, passwords, and Wi-Fi and MQTT settings, so members logging in to a room server won't notice the change.

Erase it if it ran some other firmware, or to start over. It then gets a new public key, and anyone who saved the old one will need to add it again.
